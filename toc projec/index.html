1. Mathematical Definition of a DFA

A Deterministic Finite Automaton (DFA) is formally defined as a 5-tuple:
M = (Q, Σ, δ, q₀, F)

  • Q: A finite set of states.
  • Σ: A finite alphabet of input symbols.
  • δ: The transition function δ : Q × Σ → Q (deterministic mapping).
  • q₀: The start state, where q₀ ∈ Q.
  • F: The set of accepting / final states, where F ⊆ Q.

2. Thompson's Construction Algorithm (Regex → ε-NFA)

Ken Thompson's algorithm constructs an ε-NFA inductively from the syntax of regular expressions:

  • Base Symbol 'a': Two states connected by edge labeled a.
  • Concatenation (AB): The accept state of A connects to the start state of B via an ε transition.
  • Alternation (A | B): New start state forks with ε to A.start and B.start; accepts merge with ε into a new accept.
  • Kleene Star (A*): Introduces an ε-loop for repetition and an ε-bypass for 0 occurrences.

Time & Space Complexity: O(n) where n is the length of the regular expression.

3. Powerset / Subset Construction (ε-NFA → DFA)

Invented by Michael O. Rabin and Dana Scott (1959 Turing Award):

  • Computes ε-closure(S): the set of states reachable via only ε-transitions from state set S.
  • Each state in the DFA corresponds to a distinct subset of NFA states.
  • Transition on symbol a: DFA_Next = ε-closure(move(DFA_Current, a)).
  • A DFA state is accepting if it contains at least one NFA accepting state.

Complexity: Up to 2^|Q_NFA| worst-case states, but in practice typically linear/polynomial for standard expressions.

4. Hopcroft's Algorithm (DFA Minimization)

Finds the unique minimal state DFA accepting the same language (Myhill-Nerode Theorem):

  • Starts by separating states into two equivalence classes: F (accepting) and Q \ F (non-accepting).
  • Repeatedly partitions equivalence classes whenever two states transition to different classes on any alphabet symbol.
  • Terminates when no further partitions occur, yielding the minimal DFA with the smallest possible number of states.
